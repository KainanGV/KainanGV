# Hi, I'm Kainan 👋

A **Full-Stack Software Engineer** passionate about distributed systems, cloud architecture, and building reliable, scalable platforms. I enjoy exploring new technologies, contributing to open source, and sharing what I learn along the way.

---

## 🎯 What I do

- **Backend engineering** — Java, Spring Boot, Node.js, C#/.NET, Python, Elixir
- **Cloud & infrastructure** — AWS, Azure, Kubernetes, Docker, Terraform
- **Distributed systems** — event-driven architectures, microservices, observability
- **Full-stack delivery** — React, Next.js, TypeScript, GraphQL, REST APIs
- **LLMs in the loop** — pragmatic, repeatable patterns for engineering tasks
